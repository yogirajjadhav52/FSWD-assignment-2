
# Question 3: Simple Counter using React

## Aim
To create a simple counter application that increments,
decrements, and resets the count dynamically using React state
and onClick event handlers.

## Concepts Used
- React useState Hook
- State Management
- onClick Event Handler
- Functional Components
- JSX

## Component

### Counter.jsx
Displays the current count and provides three buttons:
- Increment: increases the count by 1.
- Decrement: decreases the count by 1.
- Reset: sets the count back to 0.

### App.jsx
Imports and renders the Counter component.

## How to Run
1. Run `npm install`.
2. Run `npm run dev`.
3. Open the localhost URL shown in the terminal.
