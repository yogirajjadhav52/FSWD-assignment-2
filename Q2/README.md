
# Question 2: StudentCard Component

## Aim
To create a stateless functional component named StudentCard that
displays a student's name, roll number, and branch using JSX.

## Concepts Used
- Stateless Functional Components
- JSX
- React Component Import and Export
- Component Rendering

## Components

### StudentCard.jsx
Displays the student's name using an h2 tag and the roll number
and branch using two p tags, all inside a div.

### App.jsx
Imports and renders the StudentCard component.

## Expected Output

Student Name: Bhanu

Roll Number: 101

Branch: CSE

## How to Run
1. Run `npm install`.
2. Run `npm run dev`.
3. Open the localhost URL shown in the terminal.
