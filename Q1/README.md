
# Question 1: Greeting Component in React

## Aim
To create a functional component named Greeting that displays
"Welcome to FSWD" inside an h1 tag using JSX and render it
inside the App component.

## Concepts Used
- React Functional Components
- JSX
- Import and Export
- Component Rendering

## Components

### Greeting.jsx
Creates a Greeting component that displays the message
"Welcome to FSWD" inside an h1 tag.

### App.jsx
Imports the Greeting component and renders it inside the App component.

### main.jsx
Renders the App component into the HTML page using ReactDOM.

## Expected Output

Welcome to FSWD

## How to Run
1. Install dependencies using `npm install`.
2. Start the development server using `npm run dev`.
3. Open the localhost URL displayed in the terminal.
